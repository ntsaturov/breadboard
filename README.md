#### Отправка поста в Telegram-канал

Настройка (один раз):

1. Создать бота через [@BotFather](https://t.me/BotFather) (`/newbot`) и сохранить токен.
2. Добавить бота в канал администратором с правом публиковать сообщения.
3. Создать файл `.env` в корне репозитория (он в `.gitignore`):

```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHANNEL_ID=@имя_канала
```

Для приватного канала вместо `@имя_канала` указывается числовой id вида `-100...`.
4. Поставить зависимость, если её нет: `pip3 install pyyaml`.

Отправка — после того как пост запушен в `main`:

```
WAIT_FOR_PAGE=900 python3 .github/scripts/telegram_post.py _posts/info/2026-09-24-foreword.md
```

Скрипт покажет превью сообщения и спросит подтверждение. `WAIT_FOR_PAGE=900` — подождать
до 15 минут, пока GitHub Pages опубликует страницу, чтобы ссылка в канале не вела на 404.
Если пост уже на сайте, переменную можно не указывать.

Полезное:

- `DRY_RUN=1 python3 .github/scripts/telegram_post.py <пост>` — только посмотреть сообщение, без отправки.
- `YES=1 ...` — отправить без подтверждения.
- Можно передать несколько постов сразу.
- `telegram: false` во front matter поста — скрипт его не отправит.
- Длинные посты (больше 4096 символов) обрезаются по абзацам со ссылкой «Читать полностью в блоге».
